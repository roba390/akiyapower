# Akiya Power Tech — Training Center Website

## About the Project

Akiya Power Tech is an EV technical training center. This site was built
to help them share training information, showcase courses, and let
prospective students get in touch.

The site was developed as **freelance work** — from client requirements
through design, development, and deployment.
